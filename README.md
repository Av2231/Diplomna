# Diplomna

Native Android application developed as my Bachelor's Degree project at the Technical University of Sofia.

The application communicates with a custom Spring Boot backend through a REST API.

## Tech Stack

### Android

* Java
* Android SDK
* Gradle

### Backend

* Java
* Spring Boot
* MongoDB
* REST API

Backend repository:

https://github.com/Av2231/Diplomna-Backend

## Features

* User registration and login
* User profiles
* Profile pictures
* Comments
* Ratings
* Reservations
* Backend API integration

## Run Locally

Clone the project:

```bash
git clone https://github.com/Av2231/Diplomna.git
cd Diplomna
```

Open the project in Android Studio and allow Gradle to sync.

Start the backend separately:

https://github.com/Av2231/Diplomna-Backend

Configure the application to use the correct backend address, then run it on an emulator or physical Android device.
